Strix Halo Server bare-metal setup

This form creates the Butane configuration to install Fedora CoreOS and automatically rebase it to the Strix Halo image you select here, using uCore's supported first-install bootstrap.

Before you begin

Prepare a SHA-512 password hash on this computer. In a terminal, run openssl passwd -6, enter your chosen password when prompted, then copy the resulting hash into the form. Do not enter your plain-text password here.

SSH login is optional. You can paste multiple public keys or upload multiple files containing public keys. Never enter or upload a private key.

All values and uploaded key contents stay in this browser session. The page does not submit, transmit, store, or log them; it only fetches the shared Butane template. The page has no analytics or form-submission endpoint. The downloaded Butane file contains account access information; keep it private.

Use latest for the newest build or enter a version tag such as vYYYY.MM.DD-HHMMSS-rRUN_NUMBER.

You can paste keys, upload one or more files, or do both. Files may contain one public key per line.

Configuration ready

Copy the configuration below or download it to the Fedora Workstation Live environment. It automatically installs your selected Strix Halo image during the first-boot bootstrap.
