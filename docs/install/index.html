Strix Halo Server bare-metal setup

This form creates the Butane configuration to install Fedora CoreOS and automatically rebase it to the Strix Halo image you select here, using uCore's supported first-install bootstrap. For supported variants, it can also provision the same first-boot application settings as the variant setup scripts.

Before you begin

You can enter an existing SHA-512 password hash or switch to password entry; in password mode, the page creates a salted SHA-512-crypt hash locally in your browser. The password is not sent to a server, stored, or logged.

SSH login is optional. You can paste multiple public keys or upload multiple files containing public keys. Never enter or upload a private key.

Variant settings are optional. Arcane Manager's encryption key can be generated in this browser or entered manually. All values and uploaded key contents stay in this browser session. The page does not submit, transmit, store, or log them; it only fetches the shared Butane template. The page has no analytics or form-submission endpoint. The downloaded Butane file contains account access information and variant credentials; keep it private.

Use latest for the newest build or enter a version tag such as vYYYY.MM.DD-HHMMSS-rRUN_NUMBER.

Paste a hash from openssl passwd -6, or choose password entry to have this page create one locally.

You can paste keys, upload one or more files, or do both. Files may contain one public key per line.
